How these were measured
  • Recorded with ros2 bag record: /rslidar_points, /rslidar_imu_data and the two temperature topics. The lidar did not move during the test; the IMU shows no motion.
  • Pass marks used for the status labels: point clouds within 0.05 Hz of 10 Hz, IMU within 1 Hz of 200 Hz, main board swing under 2 °C, top board under 60 °C. Dropout limits on the gap charts: 150 ms for point clouds, 20 ms for IMU.
  • Rates and gaps use the time each message reached the recorder. Latency is arrival time minus the cloud's stamp, which marks the first point, so it includes the 100 ms a scan takes.
  • Temperatures come from bytes 38–41 of each point-data packet header, decoded the same way as RoboSense's rs_driver (0.0625 °C steps). The main board runs far hotter than the air, so compare it with the lidar's web page rather than with room temperature.
  • Range repeatability compares every 10th full scan pixel by pixel and keeps only pixels that returned in at least 95% of them.
  • The short-scan slice and the blind sector were measured on a sample of 40 scans. The share of short scans counts all 35,969.
